# 程式自控模糊：分階段計畫

目標：ResourceWatch 的背景模糊由程式自己的設定頁控制（強度、雜訊、飽和度、對比、亮度、圓角），不受 KWin 全域模糊設定影響，也不影響其他程式。

前提：Wayland 下程式讀不到自己視窗後方的畫面，真正的背景模糊只能在合成器內完成，更換程式語言或 UI 框架都無法改變。
因此做法是自製一個只作用於 ResourceWatch 視窗的 KWin effect 外掛，參數由 ResourceWatch 寫入設定檔，外掛即時讀取。

## 階段 1：KWin 外掛與程式端串接 ✅

- [x] `kwin-effect/`：由 KWin 6.8.2 內建 blur 分支出 `resourcewatch_blur`，只模糊 ResourceWatch 視窗，圓角由 shader 裁切。
- [x] 參數檔 `~/.config/resourcewatch/kwin-blur.ini`，外掛監看並即時套用。
- [x] `crates/app/src/kwin_blur.rs`：讀寫參數檔、偵測外掛是否已載入。
- [x] 設定頁「外觀」卡片新增五個模糊參數欄位；外掛未載入時退回原本的合成器模糊並顯示安裝提示。
- [x] `kwin-effect/build.sh`：在容器內對主機的 KWin 版本編譯並安裝到家目錄。
- [x] 在獨立的巢狀 KWin 內驗證：外掛載入、只模糊 ResourceWatch、改參數檔即時生效。

## 階段 2：實機驗證（需要重新登入）

- [ ] 重新登入後確認 KWin 透過 `QT_PLUGIN_PATH` 載入外掛（設定頁出現模糊參數欄位）。
- [ ] 在實際桌面檢查：圓角邊緣、最大化／半邊貼齊、多螢幕與不同縮放比例、總覽特效進出。
- [ ] 檢查拖動與縮放視窗時的效能（NVIDIA）。
- [ ] 依實際觀感決定各參數預設值。

## 階段 3：介面調整

- [ ] 模糊參數由數值欄改為滑桿（拖動時即時預覽）。
- [ ] 依新的模糊效果重新調整 `theme.slint` 的玻璃色（視窗紗、側欄、卡片透明度）。
- [ ] 評估分區模糊（例如側欄與卡片使用不同強度）是否需要；需要時在參數檔加入區域清單。

## 階段 4：安裝與維護

- [ ] `install.sh` 整合 `kwin-effect/build.sh`。
- [ ] KWin 更新後自動偵測版本不符並提示重編（目前只會退回合成器模糊）。
- [ ] 模糊強度上限延伸（上游保留的 1/32 降採樣層級）。
- [ ] 評估非 KDE 桌面的退路（不透明底色或桌布假模糊）。
